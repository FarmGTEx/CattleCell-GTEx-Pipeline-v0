========================================================================
         Tissue & Celltype Sharing (MashR) 自动化管道使用说明书
========================================================================

一、 管道总体简介
本管道是一套专门针对多组织（Bulk）与多细胞类型（Celltype）层面的 QTL 共享性分析
工作流（基于先验贝叶斯框架的 MashR 算法）。
全套流程由总控 Bash 脚本（run_mashr_pipeline.sh）一站式管理，根据传入的模式参数
（--mode），自动顺序嵌套调度 4 个数据准备集群脚本与 1 个核心运算调用脚本。
管道全面支持纯命令行长参数指定基座环境、运行时终端日志实时同步双写（Tee机制）、以及
基于系统状态码（Exit Code）的致命错误自动化熔断机制。

二、 文件结构规范
交付与运行前，请确保以下所有脚本与核心工具放置于服务器的同一个文件夹下：
├── run_mashr_pipeline.sh                       # 命令行长选项总控脚本
├── Bulk-sharing-Prepare-MashR-Random.sh        # 组织层面-随机集准备脚本
├── Bulk-sharing-Prepare-MashR-Strong.sh        # 组织层面-显著集准备脚本
├── Celltype-sharing-Prepare-MashR-Random.sh    # 细胞层面-随机集准备脚本
├── Celltype-sharing-Prepare-MashR-Strong.sh    # 细胞层面-显著集准备脚本
├── run_MashR.sh                                # MashR 核心运算调度脚本
├── MashR-random_subset.R                       # 随机子集抽样 R 脚本
├── run_MashR.R                                 # MashR 贝叶斯估算 R 脚本
├── combine_signif_pairs_tjy.py                 # 显著对合并工具 (Python)
├── extract_pairs_tjy.py                        # 关联对提取工具 (Python)
└── mashr_prepare_input.py                      # 矩阵格式化转换工具 (Python)

运行启动后，管道会自动在当前目录下创建：
└── mashr_pipeline_logs/                        # 存放各模块运行时终端实时同步的日志目录

三、 各分步模块功能详述与改动说明

本管道在升级重构时，遵循“严禁改动甲方核心业务与底层计算逻辑”的最高交付原则。
3个 Python 脚本（.py）和 核心 R 脚本（run_MashR.R）内部的矩阵解构算法保持原样。

------------------------------------------------------------------------
[模块 1] Bulk-sharing-Prepare-MashR-Random.sh & Strong.sh
------------------------------------------------------------------------
- 核心功能：
  Random 脚本负责扫描常规 beQTL 结果中的所有关联对，调用 Python 工具合并并随机抽样
  构建包含 1,000,000 个测试对的 Null Correlation 矩阵。
  Strong 脚本负责筛选各组织经 Permutation 校正后的显著 eGene 关联对，提取对应的 Z-score
  矩阵作为真实效应集。
- 核心改动说明：
  1. 【清空删库问题】原脚本末尾存在无保护的 `rm -rf /scratch/$USER/$SLURM_JOBID`。
     如果用户在本地终端直接用 bash 运行，变量为空会导致毁灭性的删库后果。现已彻底拔除。
  2. 【解耦路径】将原本写死的物理绝对路径全部替换为总控端分发过来的 `${NOMINAL_DIR}` 
     与 `${OUTPUT_DIR}` 变量。
  3. 【统一寻址】利用 `${SCRIPT_DIR}` 变量接管了内部调用的 Python 脚本，防止换路径或
     换服务器后报 `command not found`。

------------------------------------------------------------------------
[模块 2] Celltype-sharing-Prepare-MashR-Random.sh & Strong.sh
------------------------------------------------------------------------
- 核心功能：
  与 Bulk 层面对应，专门针对单细胞解密后的细胞特异性 cseQTL 结果进行双重嵌套目录扫描，
  分别构建细胞特异性效应下的随机子集矩阵（默认 10,000 个测试对）与显著效应矩阵。
- 逻辑死穴修复与改动：
  1. 【修复原版缺失变量 Bug】原版 Random 脚本第 69 行将 `#subset_size=10000` 误注释掉，
     导致下游传入 Python 的 `--subset` 参数为空直接中断闪退，并在执行 `mv` 命令时报 
     `No such file or directory`。现已通过系统变量自动安全接管修复。
  2. 同样彻底拔除了末尾的删库命令，并将所有硬编码路径解耦为动态变量环境。

------------------------------------------------------------------------
[模块 3] MashR-random_subset.R
------------------------------------------------------------------------
- 核心功能：
  在大样组织层面合并抽样时，顺序载入各染色体分块生成的 Z-score 矩阵，合并后执行随机抽样
  并序列化导出为标准的 `.RDS` 对象文件。
- 核心改动说明：
  1. 【修正解释器环境】原代码第一行写死为原作者极具私有化的集群 R 路径 
     `#!/BIGDATA2/scau_hzhang_1/.../bin/Rscript`，在新服务器上必报环境缺失闪退。现已
     将其修改为标准的全局环境寻址路径 `#!/usr/bin/env Rscript`。
  2. 【100%保留甲方原逻辑】完全保留了甲方原有的基于位置的 `ARGS[1]` 参数接收方式，
     且完全维持了其原本写死的 `for (CHR in 1:18)` 染色体循环界限与 `rbind` 堆叠算法，
     不碰任何业务逻辑，确保产出的 RDS 结果与原版绝对无缝一致。

------------------------------------------------------------------------
[模块 4] run_MashR.sh & run_MashR.R
------------------------------------------------------------------------
- 核心功能：
  多线程载入构建好的 Strong 矩阵与 Random 矩阵。首先利用随机集估计无效相关性结构（Vhat），
  随后计算数据驱动的协方差矩阵（PCA + ED），拟合混合比例模型（mixture proportions），
  最终计算后验概率并导出 lfsr（局部错误发现率）与 pm（后验均值）等 9 类核心指标 RDS。
- 核心改动说明：
  1. 删除了末尾危险的集群清理指令，确保本地运行的绝对资产安全。
  2. 将写死的 strong_file 和 random_file 输入输出路径全部使用 Bash 环境变量进行动态传递。
  3. 核心加速配置（USE_OPENMP=1 等）以及底层的贝叶斯核心估算算法一字未改，保证运算效能。

四、 运行故障排查与熔断说明
1. 管道在执行时通过 `tee` 命令打通了双向标准流。所有的矩阵合并、Python 提取进度、
   以及 R 语言中 mashr 软件包运行的 mixture proportions 拟合迭代，都会【实时在终端屏幕上
   滚动显示】，同时自动向 `mashr_pipeline_logs/` 下对应的 log 文件写入留底。
2. 管道内嵌最高级别的 PIPESTATUS[0] 错误码拦截。一旦 Python 的 pandas 抛出异常、或者
   R 语言因为矩阵行列名不匹配触发 `stop()` 崩溃，总控脚本会【一秒钟内立即实施安全熔断】，
   卡死后续的所有流转，并在终端直接以红字提示非零的 Exit 错误码，绝不容许脏数据蔓延。

五、 管道终端一键调用实例命令

本控制脚本提供 `--mode` 开关，可一站式无缝切换两种业务分析。

【实例 1：跑大样组织层面的共享（Bulk 模式）】
bash run_mashr_pipeline.sh \
  --project_dir "/faststorage/project/cattle_gtexs" \
  --mode bulk

【实例 2：跑细胞类型层面的共享（Celltype 模式）】
bash run_mashr_pipeline.sh \
  --project_dir "/faststorage/project/cattle_gtexs" \
  --mode celltype
